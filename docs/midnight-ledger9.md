# Midnight ledger 9 adapter

Stagenet uses a separate ledger 9 rc.3 / wallet SDK beta.2 adapter. Mainnet and
Preprod retain the existing ledger 8 stack. This is the wallet portion of
[Nexus #984](https://github.com/Gero-Labs/nexus/issues/984) and requires the matching
sidecar release before Stagenet writes can be enabled.

## Supported paths and limits

The adapter builds on the existing unshielded transfer orchestration. It decodes
the sidecar transaction with ledger 9, validates its embedded network, balances
DUST, and signs the complete canonical intent. Native DUST registration also
validates the supplied signing payload against the serialized transaction before
unlocking keys. Public keys and signatures use the new tagged Schnorr API while
persisted public-key identity remains unchanged.

Stagenet shielded transfers, shield/unshield swaps, browser-local proving,
ZKPAAS, and cross-device proving return an explicit unsupported error. Remote
sidecar proving remains the supported transfer path. Sponsored multi-wallet DUST
is not certified by the current tests.

Ledger 9 DUST checkpoints use the separate `stagenet-ledger9-rc3` namespace.
The adapter restores its own checkpoints or cold-replays; it does not yet consume
Nexus global snapshots. The initial replay may take substantially longer than a
warm restore. A timeout fails the operation and stops the wallet.

## Verification and rollout

Run `npx vitest run src/chains/midnight src/services/midnight-tx.ledger.spec.ts`
for both ledger lines, controlled DUST lifecycle tests, and transaction routing.
The interoperability fixture is generated by the real Nexus sidecar script
`sidecar/scripts/generate-wallet-signing-fixtures.mjs`. It uses public synthetic
keys and nonexistent UTxOs, which must never be funded.

For all production bundles, run `node scripts/build-isolated-extension.mjs .`
in a disposable checkout after `npm ci`. The helper creates isolated build
configuration and refuses to overwrite existing environment or manifest files.
It does not require repository secrets or a cross-repository access token.

The Nexus gate `STAGENET_WRITES_ENABLED` remains off by default. Before enabling
it, verify real DUST circuit proofs, funded registration and transfers, cold
synchronization, restart/restore, and a ledger 8 Preprod regression. Synthetic
signature tests and browser UI tests do not prove chain acceptance. No mainnet
funds are required for this rollout verification.
