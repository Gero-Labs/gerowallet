# gero-sync: Push-Based Wallet Sync Service — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace Ably with a self-hosted push-based wallet sync service that monitors stake addresses and proactively pushes transaction data to connected Gero Wallet clients via WebSocket.

**Architecture:** A new `gero-sync` Spring Boot microservice embeds YACI Store starters for real-time Cardano chain sync. On each new block, a Spring `@EventListener` extracts stake addresses from transactions, matches them against a per-pod in-memory registry of subscribed WebSocket clients, and pushes relevant transaction data (CBOR + account info) only to affected wallets. The frontend replaces its 470-line Ably service with a ~150-line native WebSocket client. gero-backend's entire Ably stack is removed.

**Tech Stack:** Spring Boot 3.5.4, Java 21, YACI Store 2.0.0 starters, Spring WebSocket, PostgreSQL, Vue.js 2.7 + TypeScript (frontend)

```java
// gero-sync/src/main/java/io/gerowallet/sync/registry/StakeAddressRegistry.java
package io.gerowallet.sync.registry;

import io.gerowallet.sync.model.ClientSession;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Component;
import org.springframework.web.socket.WebSocketSession;

import java.util.Collections;
import java.util.Map;
import java.util.Set;
import java.util.concurrent.ConcurrentHashMap;
import java.util.stream.Collectors;

@Slf4j
@Component
public class StakeAddressRegistry {

    // stakeAddress -> set of ClientSessions watching it
    private final Map<String, Set<ClientSession>> addressToSessions = new ConcurrentHashMap<>();
    // sessionId -> ClientSession (for cleanup on disconnect)
    private final Map<String, ClientSession> sessionIndex = new ConcurrentHashMap<>();

    public void register(ClientSession clientSession) {
        String addr = clientSession.getStakeAddress();
        String sessionId = clientSession.getSession().getId();

        // Remove any previous registration for this session
        unregister(clientSession.getSession());

        addressToSessions
                .computeIfAbsent(addr, k -> ConcurrentHashMap.newKeySet())
                .add(clientSession);
        sessionIndex.put(sessionId, clientSession);

        log.info("Registered session {} for stake address {} (lastSyncedBlock={})",
                sessionId, addr, clientSession.getLastPushedBlock());
    }

    public void unregister(WebSocketSession session) {
        ClientSession removed = sessionIndex.remove(session.getId());
        if (removed != null) {
            String addr = removed.getStakeAddress();
            Set<ClientSession> sessions = addressToSessions.get(addr);
            if (sessions != null) {
                sessions.remove(removed);
                if (sessions.isEmpty()) {
                    addressToSessions.remove(addr);
                }
            }
            log.info("Unregistered session {} for stake address {}", session.getId(), addr);
        }
    }

    public Set<ClientSession> getSessionsByStakeAddress(String stakeAddress) {
        return addressToSessions.getOrDefault(stakeAddress, Collections.emptySet());
    }

    public Set<String> getAllStakeAddresses() {
        return Collections.unmodifiableSet(addressToSessions.keySet());
    }

    public Set<ClientSession> getSessionsWithPushesAfter(long blockHeight) {
        return sessionIndex.values().stream()
                .filter(cs -> cs.getLastPushedBlock() > blockHeight)
                .collect(Collectors.toSet());
    }

    public int getSessionCount() {
        return sessionIndex.size();
    }

    public ClientSession getBySessionId(String sessionId) {
        return sessionIndex.get(sessionId);
    }
}
```

```java
import io.gerowallet.sync.service.CatchUpService;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Component;
import org.springframework.web.socket.CloseStatus;
import org.springframework.web.socket.TextMessage;
import org.springframework.web.socket.WebSocketSession;
import org.springframework.web.socket.handler.TextWebSocketHandler;

@Slf4j
@Component
@RequiredArgsConstructor
public class WalletSyncHandler extends TextWebSocketHandler {

    private final StakeAddressRegistry registry;
    private final CatchUpService catchUpService;
    private final ObjectMapper objectMapper;

    @Override
    public void afterConnectionEstablished(WebSocketSession session) {
        log.info("WebSocket connected: {}", session.getId());
    }

    @Override
    protected void handleTextMessage(WebSocketSession session, TextMessage message) throws Exception {
        JsonNode node = objectMapper.readTree(message.getPayload());
        String type = node.path("type").asText();

        switch (type) {
            case "SUBSCRIBE" -> handleSubscribe(session, objectMapper.treeToValue(node, SubscribeMessage.class));
            case "SYNC_CHECK" -> handleSyncCheck(session, objectMapper.treeToValue(node, SyncCheckMessage.class));
            default -> log.warn("Unknown message type '{}' from session {}", type, session.getId());
        }
    }

    private void handleSubscribe(WebSocketSession session, SubscribeMessage msg) {
        var clientSession = new ClientSession(
                session, msg.getChain(), msg.getNetwork(),
                msg.getStakeAddress(), msg.getLastSyncedBlock()
        );
        registry.register(clientSession);

        // Trigger catch-up for any missed blocks
        catchUpService.catchUp(clientSession);
    }

    private void handleSyncCheck(WebSocketSession session, SyncCheckMessage msg) {
        var clientSession = registry.getBySessionId(session.getId());
        if (clientSession == null) {
            log.warn("SYNC_CHECK from unregistered session {}", session.getId());
            return;
        }
        catchUpService.syncCheck(clientSession, msg.getLastSyncedBlock());
    }

    @Override
    public void afterConnectionClosed(WebSocketSession session, CloseStatus status) {
        registry.unregister(session);
        log.info("WebSocket disconnected: {} ({})", session.getId(), status);
    }

    @Override
    public void handleTransportError(WebSocketSession session, Throwable exception) {
        log.warn("WebSocket transport error for session {}: {}", session.getId(), exception.getMessage());
        registry.unregister(session);
    }

    public void sendToSession(WebSocketSession session, Object payload) {
        if (session.isOpen()) {
            try {
                String json = objectMapper.writeValueAsString(payload);
                session.sendMessage(new TextMessage(json));
            } catch (Exception e) {
                log.error("Failed to send message to session {}: {}", session.getId(), e.getMessage());
            }
        }
    }
}
```

```java
// gero-sync/src/main/java/io/gerowallet/sync/service/SyncDataService.java
package io.gerowallet.sync.service;

import io.gerowallet.sync.model.SyncPayload;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.beans.factory.annotation.Value;
import org.springframework.stereotype.Service;
import org.springframework.web.client.RestTemplate;

import java.util.ArrayList;
import java.util.List;
import java.util.Map;

@Slf4j
@Service
@RequiredArgsConstructor
public class SyncDataService {

    private final RestTemplate restTemplate;

    @Value("${apiPrefix:/internal/v1}")
    private String apiPrefix;

    /**
     * Fetch transactions for a stake address since a given block height.
     * Uses YACI Store's local address transactions endpoint.
     */
    public List<SyncPayload.TxData> getTransactionsSince(String stakeAddress, long sinceBlock) {
        List<SyncPayload.TxData> txDataList = new ArrayList<>();
        int page = 1;
        int pageSize = 100;
        boolean hasMore = true;

        while (hasMore) {
            try {
                String url = String.format("http://localhost:${server.port}%s/addresses/%s/transactions?page=%d&count=%d",
                        apiPrefix, stakeAddress, page, pageSize);
                // YACI Store returns paginated address transactions
                var response = restTemplate.getForObject(url, List.class);
                if (response == null || response.isEmpty()) {
                    hasMore = false;
                    continue;
                }

                for (Object item : response) {
                    @SuppressWarnings("unchecked")
                    Map<String, Object> tx = (Map<String, Object>) item;
                    long blockHeight = ((Number) tx.get("block_height")).longValue();
                    if (blockHeight <= sinceBlock) {
                        continue; // skip already-synced blocks
                    }
                    String txHash = (String) tx.get("tx_hash");
                    String cbor = fetchTxCbor(txHash);
                    long blockTime = tx.get("block_time") != null
                            ? ((Number) tx.get("block_time")).longValue() : 0L;

                    txDataList.add(SyncPayload.TxData.builder()
                            .hash(txHash)
                            .cbor(cbor)
                            .blockHeight(blockHeight)
                            .txTimestamp(blockTime)
                            .build());
                }

                if (response.size() < pageSize) {
                    hasMore = false;
                }
                page++;
            } catch (Exception e) {
                log.error("Error fetching transactions for {}: {}", stakeAddress, e.getMessage());
                hasMore = false;
            }
        }
        return txDataList;
    }

    /**
     * Fetch transaction CBOR from YACI Store's local endpoint.
     */
    public String fetchTxCbor(String txHash) {
        try {
            String url = String.format("http://localhost:${server.port}%s/txs/%s/cbor", apiPrefix, txHash);
            return restTemplate.getForObject(url, String.class);
        } catch (Exception e) {
            log.warn("Could not fetch CBOR for tx {}: {}", txHash, e.getMessage());
            return null;
        }
    }

    /**
     * Fetch account info for a stake address from YACI Store's account aggregate.
     */
    public SyncPayload.AccountInfo getAccountInfo(String stakeAddress) {
        try {
            String url = String.format("http://localhost:${server.port}%s/accounts/%s", apiPrefix, stakeAddress);
            @SuppressWarnings("unchecked")
            Map<String, Object> account = restTemplate.getForObject(url, Map.class);
            if (account == null) return null;

            return SyncPayload.AccountInfo.builder()
                    .controlledAmount(String.valueOf(account.getOrDefault("controlled_amount", "0")))
                    .rewardsSum(String.valueOf(account.getOrDefault("rewards_sum", "0")))
                    .withdrawableAmount(String.valueOf(account.getOrDefault("withdrawable_amount", "0")))
                    .poolId((String) account.get("pool_id"))
                    .drepId((String) account.get("drep_id"))
                    .build();
        } catch (Exception e) {
            log.warn("Could not fetch account info for {}: {}", stakeAddress, e.getMessage());
            return null;
        }
    }
}
```

```java
// gero-sync/src/main/java/io/gerowallet/sync/service/CatchUpService.java
package io.gerowallet.sync.service;

import io.gerowallet.sync.model.ClientSession;
import io.gerowallet.sync.model.SyncPayload;
import io.gerowallet.sync.model.WsMessageType;
import io.gerowallet.sync.websocket.WalletSyncHandler;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.stereotype.Service;

import java.util.List;
import java.util.Map;

@Slf4j
@Service
@RequiredArgsConstructor
public class CatchUpService {

    private final SyncDataService syncDataService;
    private final WalletSyncHandler walletSyncHandler;

    /**
     * Catch up a client that just connected or reconnected.
     * Queries YACI Store for transactions since their lastSyncedBlock.
     */
    public void catchUp(ClientSession clientSession) {
        long since = clientSession.getLastPushedBlock();
        String stakeAddr = clientSession.getStakeAddress();

        log.info("Catching up {} from block {}", stakeAddr, since);

        List<SyncPayload.TxData> txs = syncDataService.getTransactionsSince(stakeAddr, since);

        if (txs.isEmpty()) {
            log.info("No missed transactions for {} since block {}", stakeAddr, since);
            return;
        }

        SyncPayload.AccountInfo account = syncDataService.getAccountInfo(stakeAddr);
        long maxBlock = txs.stream()
                .mapToLong(SyncPayload.TxData::getBlockHeight)
                .max()
                .orElse(since);

        SyncPayload payload = SyncPayload.builder()
                .type(WsMessageType.SYNC.name())
                .block(SyncPayload.BlockInfo.builder().height(maxBlock).build())
                .transactions(txs)
                .account(account)
                .build();

        walletSyncHandler.sendToSession(clientSession.getSession(), payload);
        clientSession.setLastPushedBlock(maxBlock);

        log.info("Caught up {} with {} transactions (up to block {})", stakeAddr, txs.size(), maxBlock);
    }

    /**
     * Handle periodic SYNC_CHECK from client.
     * If client is behind, push missing data. Otherwise send SYNC_CHECK_OK.
     */
    public void syncCheck(ClientSession clientSession, long clientLastBlock) {
        String stakeAddr = clientSession.getStakeAddress();

        List<SyncPayload.TxData> txs = syncDataService.getTransactionsSince(stakeAddr, clientLastBlock);

        if (txs.isEmpty()) {
            walletSyncHandler.sendToSession(clientSession.getSession(),
                    Map.of("type", WsMessageType.SYNC_CHECK_OK.name()));
            return;
        }

        // Client missed something — push the data
        SyncPayload.AccountInfo account = syncDataService.getAccountInfo(stakeAddr);
        long maxBlock = txs.stream()
                .mapToLong(SyncPayload.TxData::getBlockHeight)
                .max()
                .orElse(clientLastBlock);

        SyncPayload payload = SyncPayload.builder()
                .type(WsMessageType.SYNC.name())
                .block(SyncPayload.BlockInfo.builder().height(maxBlock).build())
                .transactions(txs)
                .account(account)
                .build();

        walletSyncHandler.sendToSession(clientSession.getSession(), payload);
        clientSession.setLastPushedBlock(maxBlock);

        log.info("SYNC_CHECK recovery: pushed {} missed transactions to {}", txs.size(), stakeAddr);
    }
}
```

- [ ] **Step 1: Create BlockTransactionListener**

This is the heart of gero-sync. It listens to YACI Store's `AddressUtxoEvent` (fires after UTxO store processes a block) and matches stake addresses against the registry.

```java
// gero-sync/src/main/java/io/gerowallet/sync/listener/BlockTransactionListener.java
package io.gerowallet.sync.listener;

import com.bloxbean.cardano.yaci.store.events.EventMetadata;
import com.bloxbean.cardano.yaci.store.utxo.domain.AddressUtxoEvent;
import io.gerowallet.sync.model.ClientSession;
import io.gerowallet.sync.model.SyncPayload;
import io.gerowallet.sync.model.WsMessageType;
import io.gerowallet.sync.registry.StakeAddressRegistry;
import io.gerowallet.sync.service.SyncDataService;
import io.gerowallet.sync.websocket.WalletSyncHandler;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.context.event.EventListener;
import org.springframework.stereotype.Component;

import java.util.*;

@Slf4j
@Component
@RequiredArgsConstructor
public class BlockTransactionListener {

    private final StakeAddressRegistry registry;
    private final SyncDataService syncDataService;
    private final WalletSyncHandler walletSyncHandler;

    @EventListener
    public void onAddressUtxo(AddressUtxoEvent event) {
        EventMetadata metadata = event.getMetadata();

        // Skip during initial sync (catching up to tip)
        if (metadata.isSyncMode()) {
            return;
        }

        if (registry.getSessionCount() == 0) {
            return;
        }

        // Extract unique stake addresses from this block's UTxO changes
        Set<String> blockStakeAddresses = new HashSet<>();
        Map<String, Set<String>> stakeToTxHashes = new HashMap<>();

        event.getAddressUtxoList().forEach(utxo -> {
            String stakeAddr = utxo.getOwnerStakeAddr();
            if (stakeAddr != null && !stakeAddr.isEmpty()) {
                blockStakeAddresses.add(stakeAddr);
                stakeToTxHashes
                        .computeIfAbsent(stakeAddr, k -> new HashSet<>())
                        .add(utxo.getTxHash());
            }
        });

        // Match against registered stake addresses
        for (String stakeAddr : blockStakeAddresses) {
            Set<ClientSession> sessions = registry.getSessionsByStakeAddress(stakeAddr);
            if (sessions.isEmpty()) {
                continue;
            }

            Set<String> txHashes = stakeToTxHashes.get(stakeAddr);
            if (txHashes == null || txHashes.isEmpty()) {
                continue;
            }

            log.info("Block {} has {} tx(s) for stake address {} ({} session(s))",
                    metadata.getBlock(), txHashes.size(), stakeAddr, sessions.size());

            // Build SYNC payload
            List<SyncPayload.TxData> txDataList = new ArrayList<>();
            for (String txHash : txHashes) {
                String cbor = syncDataService.fetchTxCbor(txHash);
                txDataList.add(SyncPayload.TxData.builder()
                        .hash(txHash)
                        .cbor(cbor)
                        .blockHeight(metadata.getBlock())
                        .txTimestamp(metadata.getBlockTime())
                        .build());
            }

            SyncPayload.AccountInfo account = syncDataService.getAccountInfo(stakeAddr);

            SyncPayload payload = SyncPayload.builder()
                    .type(WsMessageType.SYNC.name())
                    .block(SyncPayload.BlockInfo.builder()
                            .height(metadata.getBlock())
                            .hash(metadata.getBlockHash())
                            .slot(metadata.getSlot())
                            .epoch(metadata.getEpochNumber())
                            .time(metadata.getBlockTime())
                            .epochSlot(metadata.getEpochSlot())
                            .build())
                    .transactions(txDataList)
                    .account(account)
                    .build();

            // Push to all sessions watching this stake address
            for (ClientSession cs : sessions) {
                walletSyncHandler.sendToSession(cs.getSession(), payload);
                cs.setLastPushedBlock(metadata.getBlock());
            }
        }
    }
}
```

```java
package io.gerowallet.sync.listener;

import com.bloxbean.cardano.yaci.store.events.RollbackEvent;
import io.gerowallet.sync.model.ClientSession;
import io.gerowallet.sync.model.WsMessageType;
import io.gerowallet.sync.registry.StakeAddressRegistry;
import io.gerowallet.sync.websocket.WalletSyncHandler;
import lombok.RequiredArgsConstructor;
import lombok.extern.slf4j.Slf4j;
import org.springframework.context.event.EventListener;
import org.springframework.stereotype.Component;

import java.util.Map;
import java.util.Set;

@Slf4j
@Component
@RequiredArgsConstructor
public class RollbackListener {

    private final StakeAddressRegistry registry;
    private final WalletSyncHandler walletSyncHandler;

    @EventListener
    public void onRollback(RollbackEvent event) {
        long rollbackToBlock = event.getRollbackTo().getSlot();
        long currentBlock = event.getCurrentBlock();
        String rollbackToHash = event.getRollbackTo().getHash();

        log.warn("Chain rollback detected: current={} rolling back to slot={} hash={}",
                currentBlock, rollbackToBlock, rollbackToHash);

        // Notify all sessions that received pushes for invalidated blocks
        Set<ClientSession> affected = registry.getSessionsWithPushesAfter(rollbackToBlock);

        if (affected.isEmpty()) {
            log.info("No clients affected by rollback to slot {}", rollbackToBlock);
            return;
        }

        Map<String, Object> rollbackMsg = Map.of(
                "type", WsMessageType.ROLLBACK.name(),
                "rollbackToSlot", rollbackToBlock,
                "rollbackToHash", rollbackToHash != null ? rollbackToHash : ""
        );

        for (ClientSession cs : affected) {
            walletSyncHandler.sendToSession(cs.getSession(), rollbackMsg);
            cs.setLastPushedBlock(rollbackToBlock);
            log.info("Sent ROLLBACK to session {} (stake={})", cs.getSession().getId(), cs.getStakeAddress());
        }
    }
}
```

```typescript
    lastSyncedBlock: number,
    handlers: WsHandlers
  ): void {
    this.close();
    this.chain = chain;
    this.network = network;
    this.stakeAddress = stakeAddress;
    this.lastSyncedBlock = lastSyncedBlock;
    this.handlers = handlers;
    this.intentionallyClosed = false;
    this.reconnectAttempt = 0;
    this.openConnection();
  }

  private openConnection(): void {
    if (this.intentionallyClosed) return;

    LoadingState.setConnecting(true);
    const url = `${this.WS_BASE_URL}/ws/sync`;
    debugLog('WebSocket connecting to', url);

    try {
      this.ws = new WebSocket(url);
    } catch (e) {
      debugLog('WebSocket creation failed:', e);
      this.scheduleReconnect();
      return;
    }

    this.ws.onopen = () => {
      debugLog('WebSocket connected');
      LoadingState.setConnected(true);
      LoadingState.setConnecting(false);
      LoadingState.setText('');
      this.reconnectAttempt = 0;

      // Send SUBSCRIBE message
      this.send({
        type: 'SUBSCRIBE',
        chain: this.chain,
        network: this.network,
        stakeAddress: this.stakeAddress,
        lastSyncedBlock: this.lastSyncedBlock,
      });

      // Start periodic SYNC_CHECK
      this.startSyncCheck();
    };

    this.ws.onmessage = (event: MessageEvent) => {
      this.handleMessage(event.data);
    };

    this.ws.onclose = (event: CloseEvent) => {
      debugLog('WebSocket closed:', event.code, event.reason);
      LoadingState.setConnected(false);
      LoadingState.setConnecting(false);
      this.stopSyncCheck();

      if (!this.intentionallyClosed) {
        LoadingState.setText('Wallet is Disconnected from the Network.<br>Reconnecting ...');
        this.scheduleReconnect();
      }
    };

    this.ws.onerror = (event: Event) => {
      debugLog('WebSocket error:', event);
    };
  }

  private handleMessage(raw: string): void {
    try {
      const data = JSON.parse(raw);
      const type = data.type;

      switch (type) {
        case 'SYNC':
          if (data.block?.hash && this.tipCache.get(data.block.hash)) {
            return; // deduplicate
          }
          if (data.block?.hash) {
            this.tipCache.set(data.block.hash, true);
          }
          if (data.block?.height) {
            this.lastSyncedBlock = data.block.height;
          }
          this.handlers.onSync?.(data);
          break;

        case 'ROLLBACK':
          this.handlers.onRollback?.(data);
          break;

        case 'SYNC_CHECK_OK':
          debugLog('SYNC_CHECK: caught up');
          break;

        default:
          debugLog('Unknown WebSocket message type:', type);
      }
    } catch (e) {
      debugLog('Failed to parse WebSocket message:', e);
    }
  }

  private send(data: object): void {
    if (this.ws?.readyState === WebSocket.OPEN) {
      this.ws.send(JSON.stringify(data));
    }
  }

  private startSyncCheck(): void {
    this.stopSyncCheck();
    this.syncCheckTimer = setInterval(() => {
      this.send({
        type: 'SYNC_CHECK',
        stakeAddress: this.stakeAddress,
        lastSyncedBlock: this.lastSyncedBlock,
      });
    }, this.SYNC_CHECK_INTERVAL);
  }

  private stopSyncCheck(): void {
    if (this.syncCheckTimer) {
      clearInterval(this.syncCheckTimer);
      this.syncCheckTimer = null;
    }
  }

  private scheduleReconnect(): void {
    if (this.reconnectTimer) clearTimeout(this.reconnectTimer);
    const delay = this.RECONNECT_DELAYS[
      Math.min(this.reconnectAttempt, this.RECONNECT_DELAYS.length - 1)
    ];
    this.reconnectAttempt++;
    debugLog(`WebSocket reconnecting in ${delay}ms (attempt ${this.reconnectAttempt})`);
    this.reconnectTimer = setTimeout(() => this.openConnection(), delay);
  }

  close(): void {
    this.intentionallyClosed = true;
    this.stopSyncCheck();
    if (this.reconnectTimer) {
      clearTimeout(this.reconnectTimer);
      this.reconnectTimer = null;
    }
    if (this.ws) {
      this.ws.onclose = null; // prevent reconnect trigger
      this.ws.close();
      this.ws = null;
    }
    this.handlers = {};
    this.stakeAddress = null;
    this.chain = null;
    this.network = null;
  }

  updateLastSyncedBlock(block: number): void {
    this.lastSyncedBlock = block;
  }

  isConnected(): boolean {
    return this.ws?.readyState === WebSocket.OPEN;
  }
}

const webSocketService = new WebSocketService();
export default webSocketService;
```

## Post-Implementation Notes

### Testing Strategy

1. **gero-sync integration test**: Start the service with H2 + embedded YACI Store pointing at preprod. Connect a WebSocket client, send SUBSCRIBE, verify SYNC messages arrive for known stake addresses.

2. **Frontend E2E**: Connect gerowallet to gero-sync dev instance. Login, verify connection state shows connected, verify transactions appear via WebSocket push.

3. **Rollback test**: Use YACI Store's admin API to simulate a rollback. Verify client receives ROLLBACK message and handles it.

4. **Reconnection test**: Kill and restart gero-sync. Verify client reconnects automatically and receives catch-up data.

### APEX Chain Support (Follow-Up)

APEX chains use Cardano-compatible nodes. To add APEX support to gero-sync:
1. Configure additional YACI Store chain sync connections in `application.yml` pointing to APEX nodes
2. Use separate database schemas per chain (e.g., `?currentSchema=apex_prime`)
3. The WebSocket protocol already carries `chain` and `network` in SUBSCRIBE — no code changes needed

### JWT Auth on WebSocket (Follow-Up)

Add a `HandshakeInterceptor` that validates JWT from the query parameter (`?token=xxx`) before allowing the WebSocket upgrade. Reuse the same JWT secret as Nexus.

### Monitoring

- Prometheus metrics: connected sessions count, SYNC messages sent/sec, catch-up queries/sec
- Health check: `/actuator/health` includes YACI Store chain sync status
- Alert: if connected session count drops to 0 during business hours
